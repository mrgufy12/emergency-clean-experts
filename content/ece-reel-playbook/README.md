# ECE Reel Playbook

Shareable editing playbook for **Emergency Clean Experts / Sunshine Decon** short-form video.

This repo mirrors the Grok Bot skill **ECE punchy Reel cut** so the recipe can be shared with teammates or other tools without living only inside one chat.

## What this is
A repeatable formula to turn raw job footage into a finished 9:16 Reel Juan can post — real cuts and motion, not captions glued on an uncut clip.

## What this is not
- Not a CapCut plugin (CapCut has no official remote-edit API we trust yet)
- Not permission to invent customer stories or post without Juan’s OK

## Quick formula
1. Hook 0–2s (best spray / face line)
2. Proof via 1–3s jump cuts + at least two punch tools (slow-mo, zoom, before/after, grade)
3. Brand close 3–6s
4. Short caption beats + job audio
5. Export one hero Reel (~20–35s) unless more formats are requested

See `PLAYBOOK.md` for the full recipe.

## Remotion
