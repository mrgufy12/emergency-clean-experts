# Footage

Drop job MP4s here, then point `clips[].src` at them from `src/demoProps.ts`.

Example path: `footage/01-pressure-wash.mp4`

Paths are relative to this `public/` folder. Leave `src` empty to keep a colored placeholder. Remote `https://` URLs also work.

Camera audio is muted unless you raise `sourceVolume`. The music bed stays in the lead.
